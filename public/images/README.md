# Images Directory

This directory contains all image assets for the HiTech Aesthetics website.

## Logo Files
- `logo-light.webp` - Light version of logo (for dark backgrounds)
- `logo-dark.webp` - Dark version of logo (for light backgrounds)

## Image Requirements
- **Logos**: Should be in WebP format, transparent background, max width 400px
- **Treatment Images**: WebP format, 800x600px recommended
- **Hero Images**: WebP format, 1920x1080px minimum
- **Team Photos**: WebP format, 600x600px for square crops

## Optimization Tips
1. Use WebP format for better compression
2. Keep file sizes under 200KB for logos
3. Use appropriate dimensions (don't upload larger than needed)
4. For fallback support, you can also include PNG versions
