# HiTech Aesthetics

A modern, responsive website for HiTech Aesthetics medical practice built with React, TypeScript, and Tailwind CSS.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This project is deployed on Netlify. Make sure to set the following environment variables:
- `VITE_IMAGEKIT_URL_ENDPOINT`
- `VITE_IMAGEKIT_PUBLIC_KEY`

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Decap CMS (Git-backed content editing)
- React Router v6
