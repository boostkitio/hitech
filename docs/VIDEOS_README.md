# Videos Directory

This directory contains all video assets for the HiTech Aesthetics website.

## Video Requirements
- **Format**: MP4 (H.264 codec recommended)
- **Hero Videos**: 1920x1080px, max 10MB
- **Background Videos**: Should be optimized for web, no audio track
- **Duration**: Keep background videos under 30 seconds for faster loading

## Optimization Tips
1. Use HandBrake or similar tools to compress videos
2. Remove audio tracks from background videos
3. Consider providing multiple resolutions for different devices
4. Use poster images for video fallbacks
